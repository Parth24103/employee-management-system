# Employee Management System

A beginner-friendly responsive Flask web application for managing employee records.

## Features
- Add employees
- View employees
- Search employees
- View employee details
- Edit employee information
- Delete employees
- SQLite database
- Responsive design for desktop, tablet and mobile

## Tech Stack
Python, Flask, SQLite, HTML5, CSS3, Bootstrap 5, Jinja2

## Run locally
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
